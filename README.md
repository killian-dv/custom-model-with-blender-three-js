# Custom model with Blender + Three.js

Petit projet pour apprendre à **créer un modèle 3D dans Blender** puis à **l’importer dans une scène Three.js**. Projet issu de la formation [Three.js Journey](https://threejs-journey.com/) de Bruno Simon.

## Ce que j’ai appris

1. **Blender** — Modélisation d’un hamburger (formes de base, matériaux, export).
2. **Export** — Export du modèle au format **GLB** (GLTF binaire) pour le web.
3. **Three.js** — Import du modèle dans une scène avec `GLTFLoader` + `DRACOLoader`, éclairage, sol et contrôles orbitaux.

## Lancer le projet

```bash
npm install
npm run dev
```
